# מחשב הכיתה כקיוסק

`setup-kiosk.ps1` הופך משתמש קיים ב-Windows (ברירת מחדל: `user`) לקיוסק:

- **כניסה אוטומטית:** המחשב נכנס למשתמש הזה אוטומטית כשהוא נדלק.
- **שני חלונות אפליקציה נפתחים לבד:** אתר הכיתה ו-Mashov, כל אחד בחלון משלו בלי שורת כתובת ובלי לשוניות, כמו אפליקציה מותקנת. הגלישה רגילה, לא InPrivate: Edge זוכר שם משתמש וסיסמה, והאתר שומר את הנתונים שלו. עוברים בין החלונות בלחיצה על הסמלים שלהם בשורת המשימות.
- **רק שני אתרים:** אפשר לגלוש רק לאתר הכיתה ול-Mashov.
- **רק Edge והמקלדת שעל המסך:** אי אפשר לפתוח שום תוכנה אחרת. מנהל המשימות, שורת הפקודה, ההגדרות ולוח הבקרה חסומים.
- **קיצורי דרך על שולחן העבודה:** "כיתה ז" ו"משוב". אם סוגרים חלון, פותחים אותו מחדש מקיצור הדרך.
- **שום תוכנה אחרת לא עולה בכניסה:** תוכנות הפעלה אחרות (כמו OneDrive, או קיצור דרך ישן של Edge) מועברות הצידה, כדי שלא תקפוץ ההודעה על הגבלות ושהאתר לא ייפתח פעמיים. הביטול מחזיר אותן.
- **שורת המשימות מוסתרת:** היא מופיעה כשמביאים את העכבר לתחתית המסך. רואים בה את כפתור הרשת (Wi-Fi) ואת כפתור המקלדת שעל המסך. לוחצים עליו בעכבר והמקלדת נפתחת, ומקלידים בה בלחיצות עכבר.
- **סמן עכבר גדול:** ברירת המחדל היא גודל 8 מתוך 15. לגודל אחר מוסיפים לפקודה, למשל, `-CursorSize 12`.
- **רענון בלי מקלדת:** בכל חלון: קליק ימני בעמוד ← "רענן".

## לפני ההתקנה

אם מוגדר קיוסק של Windows, מבטלים אותו קודם: הגדרות ← חשבונות ← משתמשים אחרים ← קיוסק ← הסר קיוסק.

## התקנה

מריצים ב-PowerShell **כמנהל**:

```powershell
iwr https://chabadr.github.io/kiosk/setup-kiosk.ps1 -OutFile $env:TEMP\setup-kiosk.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\setup-kiosk.ps1
```

אם אין במחשב חשבון מנהל נוסף חוץ מ-`user`, הסקריפט יוצר חשבון מנהל לתחזוקה בשם `maintenance` ומבקש לבחור לו סיסמה. **רשמו את הסיסמה.**

בסוף הסקריפט מבקש את הסיסמה של `user`, בשביל הכניסה האוטומטית. אחרי זה מפעילים את המחשב מחדש.

## יציאה לתחזוקה

התחל ← תמונת המשתמש ← יציאה (או "החלף משתמש"), ונכנסים לחשבון המנהל.

## ביטול

מתוך חשבון המנהל, ב-PowerShell כמנהל:

```powershell
iwr https://chabadr.github.io/kiosk/remove-kiosk.ps1 -OutFile $env:TEMP\remove-kiosk.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\remove-kiosk.ps1
```
