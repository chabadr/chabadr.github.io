# כיתה ז - לוח נקודות

אתר סטטי (HTML/CSS/JS, בלי build), מתפרסם ב-GitHub Pages: https://chabadr.github.io/
הנתונים נשמרים ב-Firestore (פרויקט `point-3a9cf`) ומשותפים לכל המחשבים.

## עמודים

- `index.html` - לוח הכיתה, המתיבתא, הארכיון והנוסע המתמיד.
- `z1.html` (הקישור `/z1`) - הנוסע המתמיד ז1.
- `admin.html` - ניהול (קוד כניסה נפרד): משתנים (כולל שליחת הדוח המפורט במייל, אפשר כמה שבועות), שליחת הודעות (בסופה תפריטים: "הנוסע המתמיד – ארכיון" עם עדכוני ההורים, ו"מתיבתא - ארכיון" עם ההודעות שנשלחו), היסטוריית עדכונים (בתחילתה בקשות אישור לשבוע ישן, ואז תפריט נפרד למתיבתא, לארכיון ולהנוסע המתמיד), וכפתור להנוסע המתמיד ז1.
- `up.html` (הקישור `/up`) - טופס עדכון להורים. `parent-update.html` מפנה אליו (קישורים ישנים בהודעות).

## מבנה הקוד

- `index.html` + `styles.css` + `app.js` - הלוח. `admin.html` + `admin.css` + `admin.js` - הניהול.
- אחרי שינוי באחד מקבצי ה-CSS/JS מריצים `node tests/stamp.mjs` (מעדכן את מספרי הגרסה בדפים כדי שהדפדפן לא יערבב קוד ישן עם דף חדש), ו-`node tests/check.mjs` (בדיקת תקינות; רצה גם ב-GitHub).

## קבצים נוספים

- `functions/` - פונקציות השרת (יום חדש ב-01:00, שליחת SMS מתוזמנת). הוראות ב-`functions/README.md`.
- `firestore.rules` - חוקי הגישה ל-Firestore.
- `sw.js`, `manifest*.webmanifest`, `icons/` - עבודה בלי אינטרנט והתקנה כאפליקציה.

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז נכנסים ל-http://localhost:8000
```
